# 부기사 마케팅Pro 내려받기

부기사 마케팅Pro 설치 파일과 자동 업데이트 정보를 올리는 곳이에요. 소스 코드는 여기 없어요.

- 최신 판: [Releases](https://github.com/bugisa/bugisamarketingpro/releases/latest)
- 윈도우: `BugisaAdManagerPro-setup.exe`
- 맥(애플 실리콘): `BugisaAdManagerPro-mac-arm64.dmg` · 맥(인텔): `BugisaAdManagerPro-mac-x86_64.dmg`

설치는 부기사 솔루션의 「마케팅Pro 내려받기」 단추로 하시면 컴퓨터에 맞는 파일을 골라 줘요.
